Optical recordings for the basic rotation reader
===============================================
Copy optical-events-v1 .BIN files here, then Refresh recordings in the GUI.
Nested folders are supported. Original binaries are read-only in the reader.
No recording date is required; relative microsecond event timings are used.
Raw .BIN files are ignored by Git unless deliberately added as evidence.
Start from repository root: python3 analysis-bench/reader.py --open
See analysis-bench/README.md for controls, validation and file-size limits.
